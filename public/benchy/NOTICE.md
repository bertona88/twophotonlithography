# 3DBenchy asset provenance

The geometry is derived from the official single-part `3DBenchy.stl` at
CreativeTools/3DBenchy commit `b542785f9642ab39db8a778a0ccc934b3ebd829a`.

- Source: https://github.com/CreativeTools/3DBenchy/
- Project and CC0/public-domain terms: https://www.3dbenchy.com/license/
- Original designer: Daniel Norée for Creative Tools

`3dbenchy-mesh.bin` is a deterministic browser rendering mesh and
`3dbenchy-occupancy.bin` is a deterministic dense-grid occupancy generated by
`scripts/build-benchy-assets.py`. Neither file is used as a cured-state mask;
the occupancy defines the requested scan target while Rust/Wasm owns and evolves
the surrounding three-dimensional resin state.
